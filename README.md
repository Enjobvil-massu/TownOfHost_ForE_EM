# Town Of Host For E EM

**Town Of Host For E EM（TOH4E_EM）** は、Among Us用ホストMOD **TownOfHost_ForE** をベースにした非公式Forkです。

ホストのみMODを導入し、参加者は基本的にバニラ環境のまま遊べる構成を前提に開発しています。

## 対応環境

- Among Us **2026.9.29 / v19**
- Windows x64
- BepInEx / IL2CPP
- 最新ソース: **v6190.421**

> [!NOTE]
> 公開ルームでは使用しません。  
> 非公開ルームで、参加者へMODを使用していることを伝えた上で利用してください。

## このMODについて

TownOfHost_ForEをベースに、Among Us本体アップデートへの対応、ホストMODとしての安定性改善、役職・機能追加、バニラ参加者との互換性改善などを行っています。

GitHubのソースコードと、実際に配布しているDLL / Updaterは別工程で管理しています。
